# Soundpad 🔊

Звуковая панель (soundboard) в духе [Soundpad](https://www.leppsoft.com/soundpad/):
16 пэдов на странице, несколько страниц, горячие клавиши, загрузка своих
звуков перетаскиванием — и всё это одним бинарником на Go без зависимостей
и без установки.

<p align="center"><em>Пэды цветные, играющие подпрыгивают эквалайзером,
пустые приглашают перетащить файл.</em></p>

## Возможности

- **16 пэдов × 16 страниц** — как в Soundpad, с навигацией по страницам.
- **Горячие клавиши**: `1 2 3 4` / `Q W E R` / `A S D F` / `Z X C V`,
  `Shift` — наложение (не глушить предыдущий звук), `Пробел` — стоп всё,
  `[` `]` или `PageUp`/`PageDown` — переключение страниц, `Esc` — отмена.
- **Свои звуки**: клик по пустому пэду или перетаскивание файлов прямо в окно;
  несколько файлов подряд занимают подряд идущие пэды.
- **Меню по правой кнопке**: переименовать, громкость отдельного пэда,
  переместить на другой пэд (и на другую страницу — с обменом местами),
  заменить файл, удалить.
- **Громкость**: общая (0–300 %) и персональная для каждого пэда (×0.1…×3).
- **Длина пэда** — через сколько секунд глушить длинный звук: полезно для
  музыки и длинных реплик (значение `до конца` — играть целиком).
- **Демо-звуки из коробки**: при первом запуске программа сама синтезирует
  16 сэмплов (бочка, снейр, хэты, хлопок, колокол, аркада и т.п.) — панель
  сразу играет, даже если у вас нет ни одного файла.
- **Автоматическое сохранение**: библиотека, имена, цвета и настройки
  переживают перезапуск.
- **Отклик и надёжность**: звук декодируется сервером и отдаётся браузеру
  готовым потоком WAV, поэтому браузер никогда не «не понимает» формат;
  mp3, ogg, flac, m4a, opus и другие форматы поддерживаются через ffmpeg.

## Быстрый старт

Нужен Go 1.23 или новее (для сборки) и, желательно, FFmpeg (для форматов
кроме WAV).

```bash
cd soundpad
make build          # или: go build -o bin/soundpad .
./bin/soundpad
```

Программа откроет браузер на `http://127.0.0.1:8090` — интерфейс и есть
пульт. Библиотека по умолчанию складывается в `./sound-library`.

```bash
./bin/soundpad -addr :8090        # открыть доступ с других устройств
./bin/soundpad -dir ~/МоиЗвуки    # своя папка библиотеки
./bin/soundpad -out server        # звук играет ffplay на этой машине
./bin/soundpad -open=false        # не открывать браузер
./bin/soundpad -version
```

| Флаг | По умолчанию | Значение |
| --- | --- | --- |
| `-addr` | `127.0.0.1:8090` | адрес прослушивания (`:8090` — для всей сети) |
| `-dir` | `./sound-library` | каталог библиотеки звуков |
| `-out` | `browser` | где играть звук: `browser` или `server` (ffplay) |
| `-open` | `true` | открыть интерфейс в браузере при запуске |

## Форматы и FFmpeg

| Ситуация | Что работает |
| --- | --- |
| FFmpeg установлен (в `PATH`) | любые форматы, которые читает ffmpeg: WAV, MP3, OGG/Opus, FLAC, M4A/AAC, WMA; громкость и обрезка по длине пэда без потери качества |
| FFmpeg есть + `-out server` | то же, но звук выводит ffplay на машине с Soundpad |
| FFmpeg нет | играем только WAV силами браузера; остальные форматы не загрузятся |

Установка FFmpeg: <https://ffmpeg.org/download.html>
(Debian/Ubuntu — `sudo apt install ffmpeg`, macOS — `brew install ffmpeg`,
Windows — `winget install Gyan.FFmpeg`).

## Как звук попадает в микрофон (как в Soundpad)

Панель играет звук, а «в микрофон» его отправляет виртуальный аудиокабель:

1. Поставьте виртуальное устройство, например
   [VB-CABLE](https://vb-audio.com/Cable/) (Windows) или
   [BlackHole](https://existential.audio/blackhole/) (macOS).
2. В режиме `-out browser` переключите **выход браузера** на этот кабель
   (в Windows — «Звук → Микрофон/Устройство вывода» для браузера), а в
   голосовом чате выберите входом сам кабель.
3. Либо запустите `./bin/soundpad -out server` — тогда звук выводит ffplay,
   и достаточно сделать кабель устройством вывода по умолчанию.

## Горячие клавиши

| Клавиши | Действие |
| --- | --- |
| `1` `2` `3` `4` / `Q` `W` `E` `R` / `A` `S` `D` `F` / `Z` `X` `C` `V` | пэды 1–16 |
| `Shift` + клавиша | запустить ещё одну копию звука, не останавливая текущую |
| клик по играющему пэду | остановить этот звук |
| `Пробел` | остановить всё |
| `[` / `]`, `PageUp` / `PageDown` | предыдущая / следующая страница |
| `Esc` | закрыть меню, отменить перемещение |

## Библиотека на диске

```
sound-library/
├── soundpad.json      # настройки, имена, цвета, громкость пэдов
├── page-001/          # страница 1
│   ├── 1.wav          # пэд 1
│   ├── 2.wav          # пэд 2
│   └── …
├── page-002/
└── page-003/
```

Каждая папка `page-NNN` — страница, файл `N.wav` — звук на пэде `N`.
Папку можно копировать, синхронизировать и складывать в архив; имена файлов
намеренно простые — библиотека читается и другими программами.
Расширение `.wav` у загруженных файлов условное: внутри может лежать mp3
или ogg (декодирует ffmpeg).

## Разработка

```bash
make test    # юнит-тесты: синтез, WAV, операции с пэдами, HTTP-API
make vet
make dist    # сборка под Linux, macOS (Intel/ARM) и Windows
```

Структура исходников:

| Файл | Назначение |
| --- | --- |
| `main.go` | флаги, запуск сервера, браузер |
| `server.go` | HTTP-роуты и JSON-API |
| `store.go` | библиотека: страницы, пэды, метаданные |
| `player.go` | воспроизведение через ffmpeg/ffplay |
| `synth.go` | синтез встроенных демо-звуков + WAV-энкодер |
| `wav.go` | разбор WAV-заголовка (длительность) |
| `assets/` | интерфейс (HTML/CSS/JS), вшит в бинарник через `go:embed` |

Зависимостей у модуля нет — только стандартная библиотека Go
(`go.mod` без `require`).

## Ограничения

- Проприетарные форматы вроде WMA проверяются декодером ffmpeg при загрузке,
  но качество и совместимость зависят от сборки ffmpeg.
- При `-out browser` звук играет браузер: закройте лишние вкладки, если
  слышны щелчки, и не ставьте браузеру подавление шума микрофона.
- Доступ по сети (`-addr :8090`) не защищён паролем — не выставляйте порт
  в интернет.
